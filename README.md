# AdBoard FastAPI

**AdBoard FastAPI** — современная платформа для размещения объявлений с интерактивными возможностями. Пользователи могут продавать свои вещи, общаться через чаты и оставлять комментарии с оценкой для формирования рейтинга других пользователей. Система модерации и уведомлений по электронной почте обеспечивает контроль качества контента и информирование пользователей о важных событиях.

## Ключевые преимущества

* **Простота и удобство:** интуитивный интерфейс позволяет быстро создавать, редактировать и управлять объявлениями.
* **Эффективная коммуникация:** встроенные чаты и возможность оставлять комментарии другим пользователям с оценкой.
* **Контроль качества:** система модерации предотвращает спам и недобросовестные объявления.
* **Персонализация:** возможность добавлять объявления в избранное и получать уведомления об изменениях.
* **Гибкость и масштабируемость:** современный стек технологий (FastAPI, PostgreSQL, WebSockets, Alembic) позволяет расширять функционал.
* **Готовность к продакшену:** Docker и docker-compose обеспечивают простое и безопасное разворачивание.
* **API с документацией:** REST API через FastAPI с JWT аутентификацией и автоматической документацией Swagger/Redoc.

## Основные возможности

* Регистрация и аутентификация пользователей
* Создание, редактирование и удаление объявлений
* Встроенные чаты между пользователями
* Добавление объявлений в избранное
* Комментирование и оценка пользователей
* Уведомления по электронной почте
* Документация API через Swagger и Redoc

## Технологии

* **Backend:** Python, FastAPI
* **База данных:** PostgreSQL
* **WebSocket:** для чатов
* **Миграции:** Alembic
* **Тестирование:** Pytest
* **Docker:** Docker + docker-compose

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_репозитория>
cd AdBoard-FastAPI
```

### 2. Создание `.env` файла

Скопируйте `.env.example` в `.env` и настройте свои переменные окружения.

### 3. Запуск через Docker

```bash
docker compose up -d --build
```

Сервисы будут доступны по следующим портам:

* API: `http://127.0.0.1:8000`
* PostgreSQL: `localhost:5432`


## Работа с REST API и JWT

* Все приватные эндпоинты требуют Bearer JWT токен.
* Получение токена: `/api/v1/auth/token`
* Обновление токена: `/api/v1/auth/refresh`
* Использование токена: `Authorization: Bearer <token>`

### Документация API

* `/docs` — Swagger UI
* `/redoc` — Redoc UI

## Работа с WebSocket (чаты)

* `/chat/{chat_id}/` — подключение к конкретному чату
* `/chat_list/` — список чатов пользователя
* `/unread_count/` — количество непрочитанных сообщений

## Дополнительно

* Для изменения базы данных (PostgreSQL) можно указать свои настройки в `.env`.
* Docker volumes используются для хранения данных PostgreSQL, медиа и статических файлов.
